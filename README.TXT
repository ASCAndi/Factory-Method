PROJEKTBEZEICHNUNG: Factory-Method

PROJEKTZWECK:
Das Projekt zeigt das Entwurfsmuster "Factory Method" am Beispiel eines
Dokumenten-Systems. Es werden eine Rechnung (Invoice) und ein
Lieferschein (DeliveryNote) erzeugt und ausgegeben.

WIE IST DAS PROJEKT ZU STARTEN:
Rechtsklick auf die Klasse Main -> void main(String[] args) -> OK.
Die Ausgabe erscheint im Terminalfenster.
